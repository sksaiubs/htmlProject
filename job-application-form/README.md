# Job Application Portal – Sk Saiub

This project is a *modern, professional job application portal*
built using *HTML5, CSS3, and JavaScript*.

It simulates a *real-world hiring system UI* and demonstrates how
candidates submit applications in a clean, structured, and recruiter-friendly manner.

---

## Why This Project Matters

Recruiters and companies evaluate:
- Form structure & validation
- UI clarity
- Real-world use cases
- Clean code organization
- Practical JavaScript usage

This project demonstrates a *real hiring workflow UI*
used in modern career portals.

---

##  Skills Demonstrated

- Advanced HTML forms & fieldsets
- Semantic HTML structure
- Modern CSS styling & layout
- Responsive design
- JavaScript form handling (medium level)
